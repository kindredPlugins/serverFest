# ServerFest

ServerFest is a plugin which introduce minigame styled events - so called **fests**. These are either scheduled by admins or players can held duels against each other. Each fest is held in a seperate fest dimension and does not influence the main world and playerdata in any way.

For more reference please visit the modrinth page: [ServerFest](https://modrinth.com/plugin/serverfest)
